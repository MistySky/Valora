# Velora macOS Icons — Transparent Edition

Dark and light macOS application icons, with transparent outer corners and preserved icon interior, highlights, and subtle shadow.

Each theme contains:
- PNG: 16, 32, 64, 128, 256, 512, 1024 px, plus AppIcon.png
- macOS .iconset with 1x/2x assets
- macOS .icns

The original raster artwork was masked to remove the baked-in white outside the rounded square. This is a raster-derived mask, not an editable vector master. Review at actual Dock size before shipping.

To use: add PNG variants to your Xcode asset catalog or configure an iconset/icns for your build. Appearance switching requires explicit Xcode asset configuration.
