## 确认规则

1. 仅主屏/指定显示器时，现有单屏行为保持；所有显示器时各屏都可点击/悬停/右击设置，不再让副屏永久ignoresMouseEvents=true或compactOnly。未启用的屏幕不显示/不接收交互。
2. 各屏正常紧凑信息同步：相同歌曲、播放/暂停、封面内容与进度。展开/悬停放大、切歌预览、封面切歌翻转、展开/收起过渡、音量/输出弹出等交互或事件触发动画仅当前操作屏显示；其他屏更新内容但保持紧凑，不跟着翻转/预览/展开。常驻播放律动仍按原紧凑展示，不因“动态”误删波形功能。
3. 当前操作屏定义：点击/悬停某个已启用刘海面板时，该屏成为活动交互屏。只有一块屏的面板展开。操作另一屏刘海时旧屏按原节奏收起，新屏展开；不得一份共享expanded布尔驱动全部屏一起动。
4. 鼠标移到另一屏普通桌面区域时，不自动搬移正在展开的面板；沿用原有移出/自动收起策略，不能新造跟着鼠标跨屏瞬移的刘海。
5. 自动切歌预览：优先正在操作的面板（指针仍在其交互区域或正在拖动控件）；否则用鼠标当前所在的已启用显示器。鼠标位于未启用屏幕时，只在唯一指定显示器/主已启用显示器预览，不在未启用屏创建面板。聚焦不是NSScreen.main或前台应用窗口位置，不固定系统主屏。
6. 任一屏基础播放控制都作用于同一个系统播放器；seek/音量拖动中的交互归属锁定到原面板直到结束，其他屏事件不能夺走拖动，测试fake禁止实际播放器写。
7. 每屏命中计算基于该屏frame/geometry/localContour，透明外区域仍点透。考虑显示器非零/负坐标、不同缩放、内建实体刘海/模拟/外接pill。
8. 关闭悬停、关闭音乐、隐藏/禁用/拔掉屏幕、切换显示选择、停止/退出时取消相关待触发任务，过期回调不能在错误屏弹出。活动屏移除按确定规则回落到已启用主屏/首屏，不泄露旧面板/monitor/任务。右击“设置…”在每屏复用一个设置窗口，不因此展开其他屏。
