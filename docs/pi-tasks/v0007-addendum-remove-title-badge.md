# V0007补充：用户决定移除标题标记

用户明确说标题标记（无/露骨内容/音频格式）目前无法接入，“那就不要了，去掉”。在V0007收尾或其后完成这个小改动：删除设置中的整组标题标记控件及多余分隔线，不留灰色占位；不开发标记数据采集、不改菜单栏图标、不恢复已删除设置，不重设计现有UI。移除只供该未实现设置使用的无用接线；共用图标/控件不要误删。报告更新最终设置清单与必要构建/UI核对。

附加控制本次用户正在了解，不删除收藏/复制选项或擅自改变方案。对随机/循环只能如实说明发送系统toggle命令，播放器是否执行需实测，不能把fake命令通过等同实际生效。禁止擅自执行真实随机/循环/收藏/切歌等写操作。用户仍未恢复定时派工，完成停止。
