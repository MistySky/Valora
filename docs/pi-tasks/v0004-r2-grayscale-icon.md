# V0004-R2：菜单栏使用原图灰度版

用户最新反馈：“我觉得那个彩色的变灰就好了吧，直接v有点丑”。此要求覆盖V0004-R1单独绘制单色V的方案。

菜单栏恢复使用用户确认的Transparent完整图标构图，保留原图圆角底板、V形状、明暗层次、透明边缘，只去除颜色转为灰度；不是重画V，不是把完整图标设为template后变成实心剪影。应用包图标继续使用现有彩色浅色版，原浅深彩色资源均保留。

优先用现有Swift/AppKit或CoreImage代码在加载菜单栏图像时去饱和，避免新增图像生成/外部依赖。保持透明通道、比例和约18pt菜单栏尺寸，isTemplate=false以保留灰度层次。实际检查明暗菜单栏背景的辨识度；不要主动扩展新设置或改系统外观。移除不再使用的自绘V接线及其专用无效资源，保持修改范围最小，不触及音乐逻辑或菜单行为。

更新dist/Valora.app、必要构建和验证、报告docs/reports/v0004-r2.md，提供仅图标的小范围预览/真实显示证据，区分离屏与实屏。完成停止等Codex独立验收。其他原有项目约束继续生效，不执行真实播放控制/系统设置写入、安装发布或Git提交。
