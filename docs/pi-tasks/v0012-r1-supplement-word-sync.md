# V0012-R1 补充：逐字演唱同步与平滑度

要求：

1. 核查MediaRemote elapsed/timestamp/rate的时间基准和QRC逐字绝对时间、毫秒到秒转换，确保没有双重加行起点/网络到达时间偏移。复用播放器真实时间锚点，播放期间按时钟推演，不用歌词加载完成时刻作起点。
2. 在可见且播放的歌词视图内，用合适的低成本局部刷新/插值令逐字填色和阅读窗口连续，不盲目提升全局AppModel发布频率/网络刷新频率。布局测量避免每帧重复测整句及前缀。暂停/隐藏/关闭歌词/被动屏停止歌词动画刷新，恢复按真实时间重新定位，不追补一段动画。
