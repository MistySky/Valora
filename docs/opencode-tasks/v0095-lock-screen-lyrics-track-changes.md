## 已确认代码链路，不盲改UI

LyricsController.update以model.showsMusicActivity作为新歌词身份的必要条件；而AppModel.showsMusicActivity在真实锁屏稳定阶段返回false。换歌时身份变nil→清空timeline，不发下一首请求；请求成功回调同样要求showsMusicActivity，锁中结果会被丢弃。另外visibilityChanged以桌面screenHidden/showNotch取消所有歌词请求，没有区分锁屏音乐卡；未订阅锁状态/锁屏音乐显隐需求。

这是静态控制流证据，与用户实测一致；正式修复仍须加fake回归，不说仅凭源码已实机通过。
