- 先用fake transport/event provider复现缺口，再最小修复。可以利用已授权元数据发现时匹配到的可信节假日来源ID集合排除重复来源；不用当前单个chosenID概括全部来源。不为过滤额外扫描用户来源/调用EventKit/改订阅。
