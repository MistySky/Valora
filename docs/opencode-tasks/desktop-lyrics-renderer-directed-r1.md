# 原生歌词原型 R1 定向返修

用户已要求实际下派。由 Codex 决定以下方案，现有 OpenCode 会话执行，不重新决定优化方向。沿用当前分支和模型。先读 AGENTS.md、原任务 desktop-lyrics-renderer-directed.md，以及 docs/reports/desktop-lyrics-renderer-directed-independent.md。

## 本批必修

1. 每次连续时钟更新使用同一插值时间先选行，再求行内填充/滚动。跨行才准备文字、触发一次换句动画，并重新选择连续刷新或静态下一边界唤醒。不得提高宿主采样频率掩盖延迟。静态边界唤醒与连续更新共用正确的选行逻辑；覆盖逐字→短行、长 LRC→短行、静态→逐字、暂停恢复及 seek。
2. 当前行未变时，也必须按新时间轴真实后继与 duration 更新 lineEnd。把行尾、文字、几何的失效分开；复用已修正的生产缓存或相同语义。纯行尾更新不重建文字、不重播动画。
3. 同行的绘制属性变更不能漏更新：字距刷新 attributed string 与尺寸；颜色更新必要绘制内容；verticalOffset 更新布局；backing scale 改变更新图层倍率。保持当前生产文字绘制和度量口径，禁止通过统一生产字距或改样式迁就原型。每帧不创建 lastLineKey 字符串，移至真正行身份变化时。
4. 换句严格保留当前 0.2s easeInOut、±26pt、淡入和淡出。设定出栈层模型终态，消除动画结束后清理前闪回。用代次/层所有权处理快速连续换句，旧回调不得清除新动画；停止后清理不得重新激活渲染。完成时按当前时间而非旧 sampledAt 重绘，避免高亮/滚动回退。不得擅自用新的 reduce-motion 策略改变现有体验。
