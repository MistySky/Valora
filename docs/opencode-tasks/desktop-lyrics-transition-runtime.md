# 桌面歌词换句：运行时视口动画

用户要求直接派工。沿用原 OpenCode 会话/模型/分支，读 AGENTS.md 和 `docs/reports/desktop-lyrics-transition-static-frame.md`。以现版实验渲染器为基础，保留音符居中、空行继续换句、歌词缓存和原本的 30Hz 高亮/滚动；不改锁屏或普通构建。

## Codex 指定实现

1. 把已完成静态几何验证的方案接入**实验版运行时**：每句 17pt 视口包含文字、mask 和水平长句裁剪，换句时移动整个视口，外层由实际 `rowHeight` 裁切。上一句向上退出并淡出，下一句从下进入并淡入；保持生产的 26pt、0.2 秒 easeInOut。不要继续在固定 17pt clip 内移动文字，禁止叠加两套换句动画。
2. 同一活动 renderer 控制逐帧播放；离场行是共享缓存的静态快照，不能建立第二个 30Hz 时钟。逐帧不重新构建 SwiftUI Text/位图；旧行资源在过渡结束、隐藏、失败或卸载时释放。短句音符位置沿用已验证居中，保留空行边界唤醒、快速连续换句、前后 seek、暂停、切歌和失败整行回退。
3. 运行时过渡状态使用明确代次/身份保护；排查上次过渡状态影响测试的原因，不得关闭断言、跳过失败场景、删除既有用例或硬编码测试环境。静态几何对照仅证明裁剪；另以真实宿主触发切换、可控时间或可观察的呈现状态确认运行时确实执行完整进入/退出，不得把仅设置参数或动画计数当作视觉验收。
4. 验证短→长、长→短、空行、快速连续切换、暂停/seek、隐藏恢复、捕获失败；确认音符坐标、水平裁剪及单时钟。继续使用单个复用隔离画布，禁止真实媒体控制和批量闪窗。若离屏环境不能可靠比对动画进度，保存证据并如实列为未验，不能声称体感等价或 CPU 已测。
5. 运行普通与实验构建和相邻定向回归，普通 Release 不含实验实现。输出 `docs/reports/desktop-lyrics-transition-runtime.md`，如实记录改动、测试数、未验证效果及回退。不得打包安装、启动或替换当前 App，不提交推送；完成后停止等待 Codex 独立验收。
