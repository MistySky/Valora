# Valora 1.0.1

2026-11-06，用户授权打包 1.0.1 DMG、提交并合入 main。构建号 20，ARM64，本地 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证。

## 相对 1.0.0 的改动

- 锁屏音乐卡不再主动抢焦点：移除 `makeKey`/regular 激活策略（`activateGlassSurface`/`deactivateGlassSurface`），卡片稳定停在失焦暗色材质（用户认可的 v0056 状态）；`--lock-card-preview` 同步改为 `orderFrontRegardless`，不再 `makeKey`。
- 锁屏歌词行：
  - 歌词开关开启时保持行常驻，暂停不收缩；
  - 无歌词/当前行空缺时只显示**居中的音乐小图标**（`centersNoteWhenEmpty`），不再靠左；
  - 行出现/消失使用 `ExpansionTiming.duration` 的收放 spring，参考刘海展开节奏；
  - 刘海紧凑/展开布局不变。
- 解锁路径：`.neutralizing` 解锁分支也立即移除卡片并 detach（与 `.locked`/`.locking` 一致），不再依赖 0.85s hide 任务。
- 调查记录（V0107）保留：公开 `.glassEffect` 是非 key 下的均匀模糊、无边缘折射；`appearsActive`/`controlActiveState` 对其像素级无影响；私有 `CAFilter` 玻璃缺少可复现参数，未接入产品。

## 验证

- 安全自动回归：263 Valora + 137 ReferenceCore = **400 项 0 失败**（跳过 10 个真实窗口/状态项类，与 1.0.0 发布时同一安全子集口径）。
- 锁屏定向：32 协调器 + 14 焦点 + 3 独立焦点 + 8 歌词切换 = **57 项 0 失败**。
- Debug/Release 编译、strict/deep 签名、DMG `hdiutil verify` 通过；Release 对 `--verify*`/`--audit*` 等开发参数仍 exit 2。
- 未执行：47 项真实窗口自动测试、物理双屏、真实锁屏动画体感、真实 QQ 人声同步、真实权限/设备；解锁“中间音乐控制”残余若仍出现需用户录屏再定向。
