# Valora 1.0.4

版本 1.0.4 / build62，Apple Silicon，macOS 27+。

- 优化桌面空闲更新、鼠标移动检测和播放进度发布，减少无关界面刷新。
- 音乐设置中提供独立歌词卡，包含歌词总开关、内嵌歌词和默认关闭的锁屏歌词；关闭锁屏歌词后停止对应歌词显示与更新，音乐卡位置随之调整。
- 歌词加载和切歌期间保留刘海外框的歌词空间，减少外圈随内容可用性收缩；无歌词时内部留空，保留悬停和展开收起行为。
- 改善歌词呈现生命周期及隐藏、解锁后的恢复；本次发布准备没有额外调整动画参数。
- 封面采用有界解码，并修正小图方向与封面身份识别；媒体读取循环及时释放临时Data、JSON和字符串，避免长期保留。

集中定向回归覆盖289项。首次发现启动边界测试的条件编译层级解析误报，修正后14项启动测试复验通过；另通过打包入口/构建号检查、Release strict/deep签名、开发入口拒绝及DMG完整性/包内哈希校验。未重跑全部窗口测试、压力测试或真实多屏/锁屏组合。

沿用 Valora Self-Signed 签名身份，未Apple公证。

本版本从 `codex/lock-screen-idle-cpu` 分支发布，未合入main。
