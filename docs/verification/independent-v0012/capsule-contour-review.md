# 普通胶囊歌词态圆弧缺陷

用户于2026-10-24提供实机截图，指出圆弧不协调。当前源码确认：

- `NotchContour.stationary` 对无实体刘海、未模拟、紧凑胶囊使用 `visibleHeight / 2` 作为四角半径。
- 歌词增高后，该半径随整个双行区域增大；`NotchShape` 用同一半径绘制整个 RoundedRectangle。
- 上排封面仍使用普通胶囊原有的15.5pt尺寸及6.5pt左边距，未适配更大的上角侵入范围。用户截图可见封面靠近左上弧并有裁切观感。

此项阻止歌词紧凑胶囊外观验收通过。限定返修方向：歌词增高不应将整体强制变成总高度一半的大圆头；协调上下圆角与上排内容安全区，使封面、波形完整，歌词两侧留白合理。先用隔离真实视图对照决定曲率，保持已确认214pt总宽，不用放大宽度掩盖缺陷；渲染与命中形状保持一致。保留实体刘海、模拟刘海、无歌词胶囊及展开态成熟外形，除非有独立证据必须连带修改。

本记录仅确认缺陷与返修范围，尚未投递pi或声称修复；与本批独立验收其他确定缺陷合并为单次限定返修。
