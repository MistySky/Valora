## 1. 可见行为

### 设置

“正在播放”页新增一项 **显示歌词 / Show lyrics**，沿用现有 `SettingsToggleRow`、卡片、强调色和中文呈现；默认关闭。现有通用/正在播放设置和窗口 620×687 不变。

- 关闭时：不请求歌词，恢复原有 QuickPeek 约 2 秒切歌提示后收起。
- 打开时：有有效音乐活动时，活动屏在刘海下方保留 32pt 歌词行；切歌提示仍优先显示歌名/歌手，随后同一区域替换为当前歌词，不先收起再展开。
- 加载中、HTTP/API 失败、无匹配、无歌词、纯音乐、无同步时间文本：回退歌名/歌手，不显示错误码/堆栈。
- 总音乐开关关闭、空闲隐藏、屏幕隐藏或歌词开关关闭时取消请求并清除歌词；没有无限活动。

### 同步与呈现

- 当前行直接由 `AppModel.elapsed`、`AppModel.playing` 和已加载时间轴计算，不存在独立累加秒表。
- 暂停立即停止换行和长句滚动；恢复按播放器实际进度继续；seek 前后重新定位。
- 短句保持静态；长句使用既有 `MarqueeLabel`/测量/渐隐实现，从右向左慢速滚动；暂停停在原位置，恢复连续，换句重置滚动。
- LRC 多时间戳按 `(start, sourceIndex)` 稳定排序；空白间奏时间戳会清掉上一句并回退歌名/歌手；首句前无当前行，末尾落在最后有效行。
- `[offset]` 在解析时应用到行时间。按标准 LRC 的 delayed-position 语义，以及 LyricsKit 的 `position + timeDelay` 参考实现核对；本项目采用等价的 `lineStart + offset`。
- 不消费 QRC 合成解析器，不生成任何逐字时间/高亮；本批只支持已有真实逐行 LRC。
- 展开完整播放器沿用原布局，不新增歌词页；收起后按当前进度恢复紧凑歌词。
- 遵循 V0009：仅活动屏显示歌词/切歌提示/滚动；被动屏继续显示普通紧凑内容；切屏只在活动屏挂载歌词，不破坏共享媒体和最多一屏展开。

## 2. 实现

- `Sources/ReferenceCore/LyricsTimeline.swift`
  - `LyricsTrackIdentity`、`LyricsRequest`、`LyricsFetchResult`、`LyricsDisplayState`。
  - `LyricTimeline` 稳定排序、当前行定位、空白间奏处理。
- `Sources/ReferenceCore/MusicPreferences.swift`
  - 新增 `showLyrics`，默认 `false`；沿用 reference settings dictionary，不新增其他设置。
- `Sources/Valora/LyricsService.swift`
  - `QQMusicLyricsService` actor，原生 Swift 6 `URLSession`/async-await，复用 V0010-R1 搜索、匹配、LRC/HTTP/API evaluator。
  - 仅缓存成功的时间轴；失败不缓存；按完整歌曲/版本/时长 identity 区分。
  - actor 内 in-flight 请求去重；取消时取消底层任务。
  - 不使用 scripts 子进程、Go、第三方包、QQ 本地数据库/账户/cookie 或 QRC 解密。
- `Sources/Valora/LyricsController.swift`
  - 只由完整媒体元数据变化触发；`elapsed` tick 不触发搜索。
  - generation + identity 保护旧响应；切换/关闭/隐藏/空闲取消；失败回落。
  - `MediaController` 在完整 snapshot 写入后同步通知，避免上一首歌词多留一帧。
- `Sources/Valora/CompactLyricsView.swift`
  - 复用 QuickPeek 灰色/字体/32pt 区域；短句静态，长句 Marquee。
- `Sources/Valora/NotchView.swift`
  - 活动紧凑屏显示歌词行；切歌提示优先；歌词开启时切换不做交叉淡入，避免两段文字重叠；歌词关闭时保留原 QuickPeek transition。
- `Sources/Valora/MarqueeLabel.swift`
  - 新增 paused 状态，使用 Core Animation layer speed/timeOffset 暂停/恢复，不重建时钟。
- `Sources/Valora/AppDelegate.swift` / `AppRuntimeDefaults.swift`
  - 生产环境创建 URLSession service；QA/预览使用 `NoLyricsProvider`/`StaticLyricsProvider`。
  - 新增隔离 `--verify-lyrics <dir>` 入口；不启动媒体/音频/网络。
- 设置页与本地化：`SettingsView.swift`、`SettingsLocalization.swift`（显示歌词）。

本批没有新增第三方源码或依赖；QQ 协议来源与许可说明沿用 `docs/verification/v0010/source-license.md`（LyricsKit MPL-2.0 仅协议参考，Lyrimuse GPL-3.0 未复制/链接）。
