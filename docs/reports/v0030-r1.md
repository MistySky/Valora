## 1. 下载功能 off 动作屏障

问题根因已修复：`DownloadEngineService.resume` 原先创建未跟踪 Task；`pauseAllAndSave` 只暂停当前 active task，无法作废已排队 resume。

实现：

- `DownloadEngineService` 增加 service 生命周期/代际：
  - `activate()`：功能开启时恢复新动作；
  - `pauseAllAndSave()`：先置 suspended 并递增 generation，使旧动作失效；
  - `actionTasks` 跟踪 service 发起的 resume 动作；
  - off barrier 先取消失效动作，再暂停 manager 的所有 active tasks，等待 action Task 收尾，最后保存。
- off 后 `enqueue/start/resume/retry/resolve` 都被 `featureSuspended` 拒绝；旧视图在途动作不能重新联网。
- `DownloadMenuBarController.start()` 调用 `service.activate()`；关闭仍走 `suspendAndStop()`。
- 重新开启复用同一个 service/manager，已暂停任务不自动 resume；用户可以显式再次操作。
- partial/records 不删除；未修改下载算法。

定向回归：

- `testIndependentQueuedResumeCannotRestartAfterFeatureOff` 原两项断言保留并通过；
- 追加快速 `activate()` 后等待 600ms，任务仍 paused、activeCount 0，不复活旧 resume；
- 本地 Range `enqueue → pause → resume → pauseAllAndSave` 通过。

## 2. HolidayProvider真实传输隔离

实现：

- `HolidayEventTransport` 协议；真实 EventKit 传输使用 `EventKitHolidayTransport`，但只在 provider active + panel visible + 功能/授权 gate 通过时由 factory 懒创建。
- `EKEventStore` 不再在 `HolidayProvider` 属性初始化阶段创建；init 不再注册 StoreChanged observer。
- `HolidayProvider` 增加 `started`/`panelVisible`；`ensureEvents/refreshSource/loadEvents/finishFetch` 均在读取前核 started、面板可见、authorization gate。
- `StoreChanged` observer 仅对真实 transport 安装；面板关闭/stop/撤权后注销，回调也再次核 started、面板、授权。
- stop/hide 清除 pending range/generation，旧在途结果按 generation/panel/authorization 丢弃；重新开启可恢复读取。
- `FixtureHolidayTransport` 提供注入 sources/records 和 `calendarReadCount/eventReadCount`，绝不创建 EKEventStore。
- `HolidayProvider.nonReading()` 用于 preview/audit/QA；`CalmonCalendarModel(preview: true)` 默认使用 noop provider。
- `--verify-calendar-parity` 使用 `applyFixture`，fixtureActive 时 ensure 不再回退真实来源。
- 保留已有 Calmon 节日映射、休班角标、normal/arrangement、详情去重和同名个人事件保留规则。

定向回归：

- transport factory 在未 started/隐藏时创建数 0；授权 false 时创建数 0；
- fixture transport 的 calendar/event read counters 可观察，真实 EventKit 创建数 0；
- 快速换月时第二次 range 合并，旧结果丢弃后只启动最新范围；
- 面板隐藏后 late result 不重新填充 holiday data；
- 总开关/授权 gate off 清空节假日 badge/detail，不新增 event read；
- fixture 国庆/休、10/10 补班、10/18 重阳、详情 normal+arrangement 及同名个人事件规则保持通过。
