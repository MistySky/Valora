## 1. 原生入口三区

`UnifiedMenuBarController` 现在把一个 `NSStackView` 放进同一个 status item 的 `button`：

- 可见区域直接按 `systemMonitor → aiUsage → calendar` 排列；
- 每个区域是独立的 `UnifiedMenuBarRegionButton`（系统 SF Symbol、18pt 命中区、辅助标签、tooltip）；
- status item 长度随 1/2/3 区域为 22/44/66pt，单一 status item；不是三个 NSStatusItem；
- 所有区域左击都调用同一个 `togglePanel()`，记录 `lastRegion` 但内容相同；
- 区域右击调用同一原 `NSMenu` 快捷菜单；
- 全部模块关闭：移除区域子视图、恢复原 V 图像、恢复 squareLength，左击/右击仍能进入原菜单；
- `stop()` 移除区域视图、target/action、observer/monitor。

### 单面板

- 一个 `NSPopover` + 一个 `NSHostingController`，重复开关复用同一 identity。
- 面板是单个 Alcove 风格容器（Valora/概览标题、分隔线、模块行），不是三张独立 SettingsCard。
- 顺序和 status item 由同一个 `UnifiedMenuBarState` 派生；`setVisibleModules` 同时更新条和面板。
- 模块关闭后移除对应行/区域；全部关闭关闭 popover，不创建空面板。
- `NSPopover.behavior = .transient`，本地 Escape monitor，关闭通知清理。
