## 一、静态参考帧（生产结构复制）

在测试代码中复制 `CompactLyricsView` 当前行节点：相同 12pt semibold Text、灰色底字 + 强调色逐字 mask、短句/长句布局、17pt 内层与水平裁剪、HStack 音符 + 5pt 间距、`rowHeight` 外框 + `.clipped()`；整个歌词子视图的 `offset(y:)` / `opacity` 由测试注入，不启动 SwiftUI 动画、不改生产代码。

**有效性验证**：offset 0、opacity 1 时，fixture 与真实生产 `CompactLyricsView` 截图 **0/30208 差异像素（0.0%，均值 0.00）**，fixture 可作为基准。

## 三、视口整体移动的静态几何（候选修复）

用同一静态帧、同一注入量，把实验的**整个 17pt 视口**（含其内部水平裁剪与 mask）在 rowHeight 行内移动：

| 场景 | 偏移 | 生产可见 y | 视口整体移动后 y |
|---|---|---|---|
| 短句 | +5 | [22,54] | [22,54] |
| 短句 | −5 | [11,44] | [11,44] |
| 短句 | ±10 | [22,64] / [1,44] | [22,64] / [1,44] |
| 长句 | ±5 | [31,54] / [11,34] | [31,54] / [11,34] |
| 长句 | ±10 | [41,64] / [1,24] | [41,64] / [1,24] |

**短句与长句在 ±5/±10 的可见范围与生产完全一致（高度差 0）**——静态几何证明“把换句动画加在 17pt 视口本身、由 rowHeight 裁切”的方案能消除提前截断，且短句/长句水平裁剪与音符坐标保持。
