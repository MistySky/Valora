- 本批没有日历展示；不声称已读取/显示日程。

## 2. 授权链路

- `CalendarAuthorization.swift`：
  - `EKEventStore.authorizationStatus(for:.event)` 映射 `.fullAccess`、`.writeOnly`、`.notDetermined`、`.denied`、`.restricted`、unknown；
  - `.writeOnly` 明确**不可读**，不当作 `.fullAccess`；
  - `requestFullAccessToEvents` 仅在用户点击开关的 intent 中调用；EventKit store 延迟到请求时创建；
  - 状态读取不查询事件；没有保存/删除/修改事件、提醒事项或联系人 API。
- `AppPermissions` 新增 Calendar status、pending、generation 和 request:
  - pending 使用 `@Published`，取消立即 off；
  - 连续点击/进行中不会重复 request；
  - 成功 callback 仅完成本次仍有效 intent；拒绝/取消/失败保持 off；
  - denied/restricted 打开 Calendar 隐私设置，应用激活刷新真实状态；
  - 外部授权变化没有 pending 时不自动开启；
  - 旧 callback 不能完成新 intent。
- `PermissionToggleRouting` 用于 Calendar 实际 Binding；已拒绝/未知时手形只是状态，开关仍可操作。
- `NSCalendarsFullAccessUsageDescription` 已写入 `scripts/package.py`；当前候选非沙盒，未开启沙盒或新增 entitlement。
