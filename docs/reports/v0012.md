## 2. 可见行为

- 开启歌词时不再显示切歌歌名/歌手提示；紧凑歌词左对齐，只占原 QuickPeek 小区域；关闭歌词后恢复原居中切歌提示。
- 无歌词/加载/失败/超时：不显示歌名永久占位；3 秒未取得有效歌词即隐藏歌词行。
- 逐字行：未唱到灰色；已唱部分用歌曲封面主色；无封面回退可读灰白；颜色不受进度条样式影响。
- 长句根据真实当前 word 位置跟随，接近可用区域 65% 时向左平滑移动，偏移限制在 0..正文溢出宽度；短句不移动，换句归零；不按整句平均分字。
- 上下换句使用垂直/透明度过渡；暂停停止填色/横移/换句；恢复和 seek 按真实 `elapsed`；紧凑/展开共用同一时间轴。
- 展开态歌词始终在最底部，音量打开时顺序为播放器→音量→歌词；容器高度随真实内容增加。最多活动屏呈现动态，被动屏保持普通紧凑信息。

## 3. 请求、预算与缓存

- `LyricsController` 以完整歌曲身份为请求单位；普通 elapsed tick、暂停/恢复、展开/收起/换屏不重新搜索。
- 每首歌总预算 **3 秒**（搜索 + QRC + LRC 全链路）；超时取消并隐藏歌词，迟到结果被 generation/identity 拒绝；缓存命中直接显示。
- `QQMusicLyricsService` actor：QRC 优先、失败退回真实 LRC；HTTP/API 失败不分类为歌词；in-flight 旧任务取消后新同 key 请求不会被已取消 task 卡住；旧完成不会删除新条目。
- `LyricsCache` actor：内存最多 50 首/5MiB payload，磁盘最多 50MiB，LRU；只缓存成功 timed/wordTimed；失败/超时不缓存；文件名使用 SHA-256，不含歌曲正文；原子写、坏文件移除、同版本覆盖；文件 I/O 不在主线程。
- 缓存额度是歌词 payload/文件额度，不等同整个 App RSS。
