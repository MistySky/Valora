## 2. 灰度实现

`AppDelegate.statusBarImage()` 现在：

1. 明确读取 `Contents/Resources/AppIcon.icns`（用户确认的浅色完整图标）；缺失时回退 AppKit bundle 图标。
2. 取完整 `CGImage`（保留圆角底板/边缘/阴影/透明外角）。
3. `CIImage` → `CIColorControls`，仅设置 `inputSaturation = 0`；不改变 alpha、构图、尺寸比例，不新增图像生成/外部依赖。
4. 生成 18 pt 的 `NSImage`，`isTemplate = false`，保留灰度层次（不被系统当成单色模板剪影）。
5. 菜单栏按钮仍为 `statusItem.button.image`，`.scaleProportionallyDown`、`.imageOnly`、accessibility label `Valora`；菜单点击行为不变。

应用包彩色图标未动：`AppIcon.icns` SHA256 仍为 `df342247…654`，`CFBundleIconFile=AppIcon`；V0002 的 light/dark 原始资源全部保留。
