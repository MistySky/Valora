## 3. 可用的基础日历

新增：

- `Sources/Valora/MenuBarCalendar.swift`
  - `MenuBarCalendarModel`：可见月、选中日、今天、周网格、日期详情、农历、菜单栏日期；
  - `MenuBarCalendarView`：年月标题、上/下年、上/下月、今天、周标题、完整 7 列、4/5/6 周自适应、日期选择、详情和事件区；

  - `PreviewMenuBarCalendarEvents`：隔离 preview 的明确样例事件。

实现细节：

- 使用 Foundation `Calendar`/`Locale`/`TimeZone` 和 Chinese Calendar，按日期加减而非固定 86400 秒；
- 月网格自然行数 4–6，跨年/闰年由 Calendar 计算；
- 今天、选中、周末、非本月使用不同颜色；农历作为第二行；
- 没有可靠节假日数据，未显示“调休/上班/法定假日”标记，也不联网补数据；
- 菜单栏三区中的日历区域显示实际菜单栏日期文本；生产仅显示 `.calendar` 模块，系统监控/AI 后端未接时不暴露假统计；

- 系统日期/时区/时钟/唤醒通过系统通知更新，没有 1 秒定时刷新；关闭/stop 清理观察和事件任务。

## 4. 系统日程只读 gate

- 沿用已有 `enableCalendar` 默认 false、`CalendarAuthorization`、`AppPermissions` 和单一设置授权开关；没有新增授权开关或自动请求。
- 读取条件严格为：设置开关明确开启且 EventKit 状态 `fullAccess`。
- `notDetermined/denied/restricted/writeOnly/unknown` 或开关关闭：provider 调用次数为 0，事件清空，基础月历仍可浏览；
- 只读 `EKEventStore` 事件，按选中日期本地日界查询；只取值类型，不把 EKEvent 跨 actor；
- 单个在途任务、generation 丢弃旧结果；切换日期/月份、关闭/stop、授权关闭后旧结果不复活；
- 事件按全天优先、开始时间排序；无事件显示“暂无日程”；未授权提示去现有日历设置；
- 本批实际测试/preview 使用 fake provider，没有查询用户个人日历，也没有打开真实授权/系统设置。
