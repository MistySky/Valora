## 1. 3 秒预算真实收尾

独立回归 `IndependentLyricsDeadlineTests` 的 provider 使用不可取消的 continuation，600ms 后才返回：

- 旧实现 `withThrowingTaskGroup` 在返回值后仍等待未配合的子任务，50ms 预算下 200ms 仍可能 loading。
- 改为 `LyricsDeadlineRace`：provider/timeout 两个非结构化任务竞速，任一完成即恢复 continuation，并取消另一边；不等待不合作 provider 后才更新 UI。
- timeout 后控制器立即 `unavailable`；迟到 provider 结果被 generation/identity 拒绝。
- 生产 3 秒、A→B→A、QRC 取消、晚响应不写缓存、隐藏期间不启动新请求均保持。
- 允许不可取消 provider 任务自然结束后释放，不创建每 tick 重试；控制器/UI 不持有过期结果。

## 2. 统一局部时间轴

- `CompactLyricsView` 现在由**外层单一 30Hz TimelineView**同时选行和计算 word 进度；不再出现“外层0.25秒选行、内层30Hz填字”两套时间轴。
- 局部时钟 `LyricsPlaybackClock` 锚定最近一次播放器 `elapsed` 与采样时刻，按 `playbackRate` 推演；不使用歌词加载时刻/网络返回时刻。
- 暂停或 `rate <= 0` 停止 Timeline；恢复按真实 elapsed 重新锚定；seek 立即重算当前行/字/填色/横移。
- 切换紧凑/展开、加载完成、换屏不重新请求；新视图只在当前真实 elapsed 上建立锚点，不把旧 elapsed 当作“此刻”。
- 行内 word/prefix 宽度由 `LyricMetricsCache` 按行缓存，30Hz 帧只查表、算比例/遮罩/偏移。

## 3. 连续横向跟随

- 阅读位置从固定 `word center` 改为 `before + currentWordWidth * fraction`；fraction 来自真实 word start/duration。
- 多字符 word 仍使用源 word 时间，不平均伪造字级时间。
- 边界继续 `0...正文溢出宽度`，30%–65% 阅读区；短句不移动/整体居中；seek 立即定位；暂停不刷新。
- 新增 pure regression `LyricsContinuousOffsetTests`，验证多字符 word 内 offset 连续单调且夹紧。
