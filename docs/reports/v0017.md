## 2. 可点击页面

### 通用

- 登录时启动默认 off；悬停展开默认 off；开启后才出现延迟 slider（默认 0.00 秒），slider 即时显示数值。
- 显示范围三张图卡：主显示器 / 指定显示器 / 全部显示器；均为选中描边和图案预览，不是下拉菜单。
- 指定显示器后显示“内置实体刘海 / 外接无刘海”演示屏；选择改变下方外观组。
- 主屏演示内置实体刘海，不显示模拟外观；外接无刘海和全部混合屏显示胶囊/模拟刘海两张卡；全部混合屏标注“仅用于无实体刘海的屏幕”。
- 不读取用户硬件；全部为样例状态。

### 音乐

- 音乐总开关默认 on；进度样式单色/彩色/渐变默认单色；实时波形/歌词默认 off。
- 合成播放预览随进度样式和歌词开关即时变化，不联网播放、不提供浏览器来源选择或真实控制。
- 保留一条简短说明：系统音乐软件（QQ/网易云/Apple Music/Spotify 等）的来源规则；未宣称多歌词源已实现。

### 日历

- 日期格式三张卡：年月日、月日+星期（默认）、年月日+星期；每张有固定 2026-10-24 周六的真实文本预览。
- 展开时显示日历默认 on；系统日历访问默认 off，手形仅作为状态标记，不是按钮；点击开关打开模拟对话框“允许/暂不允许”，允许才开启并消失手形；关闭不撤销模拟授权。
- 小型 2026-10 静态月历、固定 24 日周六和合成日程；不调用 EventKit、不读取个人日程。
- 说明基础月份/日期不需要授权，本页不做 Calmon 展示。

### 锁屏

- 仅一个“锁屏显示”总开关默认 on（演示方案，尚未最终确定）和合成锁屏预览（锁/09:41/日期/合成歌曲）；无天气、日历、通知等未确认功能。
- 不调用真实锁屏。

### 设备连接

- 单一总开关默认 off；手形状态；点击开关打开模拟授权对话框，允许后显示耳机缩略图；关闭不撤销模拟授权。
- 仅自动外观说明；没有 3D 选择、低电量阈值、时长或设备管理。

### 系统监控 / Codex 监控 / 关于

- 系统监控默认 on，作为尚未确定选项的预览候选：CPU 18%、内存 46%、网络 1.2/0.4，不采样真实系统数据。
- Codex 监控默认 on：5 小时额度 62%、一周额度 34%、重置示卡；不读取账号/token/文件。
- 关于：Valora 名称、版本示例 0.1.0 (1)、Alcove 视觉来源说明、查看说明按钮反馈；品牌图标不修改、无真实外链。

## 3. 一体菜单栏预览

- 窗体上方独立小条，顺序“系统监控 → Codex 用量 → 日期”，三个位置共用一个点击触发区。
- 点击任意处展开同一小面板，内容按相同顺序；系统监控/Codex 关闭时对应条项和面板行同步移除；日期样式立即更新条和面板。
- “展开时显示日历”off 只移除面板中的日历/日程部分，日期条保留；系统监控/Codex 可分别关闭，面板仍可只显示日期。
- 日期是固定样例，无单独开关；这避免把日期格式/日历展开误做成第三个模块开关。
- 不另开三个弹窗、不接快捷键、不操作真实菜单栏。
