## 2. 恢复的 Calmon 独立入口

生产 `MenuBarModuleController` 只保留：

- **系统监控**：CPU/MEM 双行文字，`metricImage` 原生 template；
- **日历**：现有 Calmon `menuBarText`（如 `10月27日 周二`），原生 template；
- 两者各自 status item、各自点击各自 NSPopover；
- 右击基础版本（禁用）/设置…/分隔线/退出；
- 软件 Outline-v7 入口、音乐菜单、刘海/歌词/设备/锁屏不变。

保留当前正确的生命周期：

- off 移除所属 status item，关闭所属 popup，停止所属后台；
- 初始 off 不启动采样/事件读取；
- on 重建入口并重连观察；
- monitor/calendar 独立 epoch，旧回调不覆盖新会话；
- stop/restart 重建 status item 并清空旧 image cache key；
- sleep/wake 按各自开关；
- 日历面板打开后才读事件，授权 gate 未通过时不读；
- 日期基本月历不等同于 EventKit 授权；月历仍可浏览。

面板/内容：

- 400pt 日历面板和 368pt 网格保持；
- `CalmonCalendarView`、农历/节假日/休班/事件去重/事项/授权流程原样；
- `MonitoringView` 原有网络/内存/进程/搜索内容保留；
- 不新建图标/仪表/大面板。
