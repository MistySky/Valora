## 1. 歌词居中与音符配色

- `CompactLyricsView` 仅在整行（音符+文字）不超过可用宽度时，将组合放在 QuickPeek 区域正中；不再保留左对齐占满宽度的空框。
- 长句仍从可用区域左侧开始，按当前 word 位置做 30%–65% 阅读区跟随；偏移限制 `0...正文溢出宽度`，不裁句首/句尾，不随每个字重新居中。
- 紧凑、展开、展开+音量共用同一规则；展开歌词保持最底部、音量在上。
- 音符由父层 `.gray` 改为歌曲封面主色（太暗时由 `lyricsAccentColor` 提亮）；未唱文字仍灰。
- QA 截图：`lyrics-short.png`、`lyrics-long.png`、`lyrics-expanded-bottom.png`；同几何下关闭歌词的原提示见 `lyrics-off-song-peek.png`。

## 2. 普通胶囊歌词态圆角

用户实机缺陷：无实体刘海的普通胶囊在加歌词后使用 `visibleHeight/2` 作为四角半径，高度增加会把上角推进封面/波形安全区。

最终选择：

- 普通胶囊基础半径仍为 `geometry.compact.height/2`（无歌词时保持原外形）。
- 歌词增高时半径**封顶在基础胶囊半径**，不再使用“总可见高度/2”；因此上排封面 15.5pt/6.5pt 左边距完整留在安全区，歌词行两侧留白也自然。
- 模拟刘海继续使用 notch contour；不伪造 `hasPhysicalNotch`；实体刘海和展开态成熟外形未改。
- 渲染 contour 与命中使用同一个 `NotchContour` 半径。
- QA：`lyrics-nonnotch-pill-compact.png`、`lyrics-nonnotch-simulated-compact.png`、`lyrics-nonnotch-simulated-expanded.png`。普通胶囊可见黑色内容宽 **214pt**、展开 **345pt**，不是 624pt 宿主宽。

## 3. 隐藏/取消/超时生命周期

- `LyricsController.update` 增加 `screenHidden`/`showNotch` 门禁：隐藏后再变更歌曲 metadata 不会发新请求；显示恢复按当前身份和尝试状态恢复，不按 tick 重试。
- `QQMusicLyricsService.fetchQRC` 不再用 `try?` 吞掉 `CancellationError`；取消直接上抛，不再继续 LRC fallback。
- `fetch` 在搜索、QRC、LRC 阶段之间检查取消。
- `lyrics` 在 `task.value` 后、写缓存前检查调用任务/底层 task 是否取消及 in-flight ID；不合作 HTTP 客户端晚返回的已取消结果不写缓存、不显示、不删除新请求条目。
- 控制器 3 秒 race 保持：超时隐藏，迟到结果由 generation/identity 拒绝；不依赖生产 URLSession 通常及时取消。
- 回归：
  - `testHiddenNotchDoesNotStartRequestOnMetadataChange`
  - `testCanceledQRCPhaseDoesNotFallBackToLRC`
  - `testCanceledNoncooperativeResultDoesNotPopulateCache`
  - `testCanceledInFlightDoesNotTrapFreshSameRequest`
  - `testControllerThreeSecondBudgetHidesLateResult`

## 4. 逐字平滑（同轮补充）

- 可见歌词行内使用 `LyricsPlaybackClock` 本地锚点 + 播放器 `playbackRate` 在 30Hz `TimelineView` 中插值；不提高全局 `AppModel.elapsed` 发布频率。
- 锚点来自播放器 last elapsed；不把网络返回/歌词加载时刻当起点。
- 暂停暂停 Timeline；恢复重新锚定；seek 由 elapsed 变化重置；隐藏/无歌词视图卸载，无空闲动画。
- 行内 word/prefix 宽度在视图初始化时计算一次，Timeline 帧不重复测量整句/前缀。
- 本地时钟测试：`LyricsPlaybackClockTests`；短/长字 duration 由真实 QRC word start/duration 提供，不平均分字。

## 4b. 时间基准与本地连续刷新

- 播放器侧：`SystemMediaSnapshot` 使用 MediaRemote 的 `elapsedTimeMicros`、`timestampEpochMicros`、`playbackRate`；`SystemMediaTimeline.position(at:)` 只按 timestamp→now 与 rate 推演一次。
- QRC 侧：word start/duration 由毫秒除以 1000 得到绝对秒；`LyricsLineContent` 直接使用 word 时间，不额外叠加行起点，也不使用网络返回时刻。
- 视图侧：`LyricsPlaybackClock` 以最近一次播放器 elapsed 为锚点、按 playbackRate 在 30Hz `TimelineView` 内插值；不提高全局 `AppModel.elapsed`/网络刷新频率。
- 暂停暂停 Timeline；恢复重新锚点；seek（向前/向后）通过 elapsed 变化立即重置锚点；切歌/新身份创建新视图锚点；紧凑/展开共享 line/key。
- 行内 word/prefix 显示宽度在视图初始化时计算一次，Timeline 帧只做索引/比例/mask/offset；不逐帧重测整句。
- fake 时钟回归：`LyricsPlaybackClockTests`（1x/2x、连续 0.1/0.2 采样、暂停、双向 anchor reset）、`testWordProgressHonorsShortAndLongWordDurations`、`testSeekIsAnExplicitAnchorResetInBothDirections`；QA 提供向前+向后 seek 截图。
