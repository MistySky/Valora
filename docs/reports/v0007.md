- `SettingsWindow` 设置显式静态窗口背景（浅色灰；深色沿用系统自适应）。
- `SettingsView` 给侧栏、内容区、顶部标题带、选中行使用上述颜色；顶部 53pt 标题带保持灰，内容页为 `#F5F6F6`。
- `SettingsCard` 使用 `#F2F3F3`；不改变布局、字体、控件尺寸、间距或导航。

## 2. 显示于图标

### 原因

“All displays” 与 “Main display” 是不同选项。原版左图多屏图标是正常差别；当前设置行硬编码 `desktopcomputer`，状态菜单把 All displays 与具体外接屏都映射为 `display`，这是实际硬编码偏差，不是应统一的图标。

### 实际改动

- `SettingsDisplayCatalog.symbol(for:)` 明确映射：
  - Main display → `desktopcomputer`
  - All displays → `display.2`
  - Built-in display → `laptopcomputer`
  - specific external → `display`
- 设置选择行使用当前 `showOnDisplay` 的动态图标；状态菜单项也使用同一映射。真实 `SettingsDisplayCatalog.selectedScreens`/`WindowCoordinator` 消费者未改。

### 证据

- `General.png`（Main 单屏）与 `General-all-displays.png`（多屏）对比
- `SettingsReductionTests.testDisplayChoiceIconsAreDistinctAndMapped`
- `AppDelegate` 只改显示子菜单图标行；未改 `statusBarImage`/Codex 菜单栏图标。

## 4. 正在播放：标题标记已移除，附加控制保留

### 原因与决定

- 用户明确要求：标题标记（None/Explicit/Format）既然无法接入，就整组移除。系统 Now Playing payload 仍没有 Explicit/露骨或音频格式字段；本次不新增采集、不保留灰色占位。
- 附加控制在旧复刻中没有消费者。系统 adapter 提供 `send 6`（Toggle Shuffle）/`send 7`（Toggle Repeat）和可选 `shuffleMode`/`repeatMode` 字段，因此 Shuffle/Repeat 可直接接线；Favorite 只有 `isLiked`/`supportsIsLiked` 读取字段，没有收藏写入命令；Copy 没有系统媒体 URL/链接字段，复制歌名不等价。

### 实际改动

- `SystemMediaSnapshot` 新增可选 `shuffleMode`/`repeatMode` 解析；缺失保持 nil，不伪造关闭状态。
- `AppModel`/`MediaController` 保存模式；`command(6/7)` 通过既有系统 adapter `send` 链路执行，真实消费者为 `MusicPlayerContent` 的额外控制按钮。
- `controlChoice` 读入并只接受 `Shuffle`/`Repeat`；旧无效值回落 Shuffle。设置页 Shuffle/Repeat 可选，默认 Shuffle；额外控制显示在展开播放器左侧，状态由系统模式字段点亮。
- 标题标记整组控件及其后的多余 `SettingsRule` 已删除；`songTitleBadge` 不再有 UI 接线或消费者；不会出现灰色占位或空分隔线。
- Favorite/Copy 保持禁用并给出具体原因：无收藏写入命令 / 无媒体链接，明确不降级为复制歌名。
- 没有新增 Music/Spotify 专用来源、权限或语言；系统单一来源不变。

### 证据

- `Now-Playing.png`（标题标记已移除；默认 Shuffle 可选、Favorite/Copy 禁用）与 `Now-Playing-repeat-selected.png`（Repeat 可选）
- `docs/verification/v0007/music-ui-verification.json` 的展开播放器合成图（额外 Shuffle 控件）
- `MediaControllerRecoveryTests.testShuffleAndRepeatCommandsUseSystemRunner`（fake source，断言 `send 6/7`，未执行真实操作）
- `SystemMediaModeSnapshotTests.testOptionalShuffleAndRepeatModesAreParsedWithoutTruthinessGuessing`

### 仍有缺口

- 真实播放器是否接受 Shuffle/Repeat 命令未执行验证；约定仍由 adapter `send 6/7` 承担，失败时现有 `mediaError` 路径提示。`shuffleMode`/`repeatMode` 缺失时状态显示保持未知/关闭视觉，不伪造。
- 标题标记选项已按用户要求删除；未开发 Explicit/Format 数据采集。
- Favorite 没有系统写入命令；Copy 没有可验证媒体链接。二者未伪装可用。
