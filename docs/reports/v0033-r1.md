## 2. 图标落实

- 顶部日期：`01`–`31` ASCII 补零；日期不随下载颜色变。
- 圆心下载箭头：空闲灰、下载蓝、完成短暂绿、暂停黄、失败红。
- 左半环 CPU 使用率，右半环内存使用率；绿色正常、>80 红、未填/未知/off 灰。
- 底部四点：前两 5H 剩余，后两周日剩余；每点 50%，按实际比例部分填充；
  >25 绿、1–25 黄、耗尽/未知灰。

  历史暂停不能覆盖正在进行；失败仍明确优先。

- 日期本地跨天单次午夜 timer，无高频 timer。
- 右击仍是版本（禁用）/设置…/退出，下载 on 才加“新建下载…”。

## 3. 展开面板

- 主面板维持 400 pt，无顶部 Valora 名称/设置齿轮。
- 上部左 CPU 百分比仪表、中间**原版单环 renderer 放大版**（不再画左右两个小圈）、右内存仪表；波形仍只来自已有监控样本历史。
- 中间单环使用同一 22pt renderer 放大到 110pt，日期/下载箭头/四点与菜单栏同源。
- 内存/磁盘两行真实已用/可用数值保留。
- 下载卡片：
  - 简短标题/任务总览；
  - 按 `createdAt` 稳定显式选择最近创建项（`CompositeDownloadSelection`），不依赖未说明的 items.first，不按进度重排；
  - 文件名/图标/真进度/大小/速度/暂停继续；空态不伪造；
  - 卡片点击打开侧面列表，行内按钮不触发卡片导航。
- Codex 卡片完整展示 5H/周剩余、真实本地重置时间、重置卡次数与逐张日期；无 chevron/Button/二级展开/重置动作。
- 下方完整 Calmon 月历（`embedsScroll:false`，主面板单一外层滚动），保留原月历/农历/节假日/授权/事件去重/字体和 400pt/368 网格；无“今日日程”摘要替代。
- 模块 off 隐藏相关区域；其他既有功能不变。

## 4. 侧面板

- 复用现有 `DownloadPopoverView`、分段进度和 Convoy 操作/冲突/删除确认。
- 宽度 400；先右后左，两侧不足时按 `CompositeSidePanelPlacement` clamp 到 visibleFrame，不超出屏幕。
- 高度取主面板实际窗口高度；主面板日历 resize 时同步。
