## 2. 菜单栏实现

`AppDelegate` 新增：

```swift
private func statusBarImage() -> NSImage {
    let iconURL = Bundle.main.resourceURL?.appendingPathComponent("AppIcon.icns")
    let image = iconURL.flatMap { NSImage(contentsOf: $0) }
        ?? NSWorkspace.shared.icon(forFile: Bundle.main.bundlePath)
    image.size = NSSize(width: 18, height: 18)
    image.isTemplate = false
    return image
}
```

- 明确使用包内 `Contents/Resources/AppIcon.icns`（V0002 已验证的浅色确认图稿）；失败时回退 AppKit 对该 bundle 的应用图标，不使用旧窗口符号。
- `statusItem.button.image` 设为 18×18，`imageScaling = .scaleProportionallyDown`，`imagePosition = .imageOnly`，`isTemplate = false`（避免彩色图被系统渲染为整块剪影），`accessibilityLabel = "Valora"`。
- `statusItem.menu`、菜单重建、播放/显示器/设置/退出菜单项及所有点击行为未变。
- 未实现浅深自动切换：包内仍使用浅色默认；深色 light/dark 两套资源仍完整保留在 `Resources/AppIcons`，没有改全局外观或新增设置。
- 构建打包仍由 `scripts/package.py` 把 `AppIcon.icns` 放入 `Contents/Resources` 并写入 `CFBundleIconFile=AppIcon`；菜单栏直接复用该资源，没有额外、未打包的路径。
