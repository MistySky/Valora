## 5. 已知限制

1. 本 harness 是独立 ad-hoc CLI，直接加载私有 MediaRemote；没有采用 Valora 现有 Perl/adapter entitlement 路径，也没有尝试新签名、entitlement 或权限绕过。zero clients 的 entitlement 归因仍然未定。
2. 私有符号存在/函数指针可用不等于信息读取成功；本次没有 `symbol_missing`，但没有 client rows。
3. 没有真实音乐+浏览器同时播放场景；不能自行启动播放器/视频制造该场景。当前样本无法验证“网页接管后继续读后台音乐”。
4. 没有测试任何定向控制；只读成功（如果未来发生）也不能证明 SendCommand/Seek 可以安全定向到同一来源。
5. 没有改动生产 `SystemMediaSource`、`AppModel`、来源 UI 或歌词/进度体验。
