# V0012-R4 交付报告：无逐字长 LRC 的可读滚动

- 任务：`docs/pi-tasks/v0012-r4-line-only-overflow.md`
  （SHA256：`53260b46249d253dd695b527d847b31adb49cafc6db8fcfdc16384c2cf6b65ef`，已核对）
- 依据：`docs/verification/independent-v0012-r3/decision.md`
- 结论：仅有 LRC 行时间、`words` 为空的长句不再永久裁掉后半句；新增行时间驱动的灰色阅读滑动，不创建逐字填色或平均字时间。短句仍居中静止，QRC word 跟随逻辑不变。

## 1. 行-only 策略

- 当 `line.words` 为空且整行超出可用宽度时：
  - 保持灰色，`fillWidth=0`，不制造已唱颜色/假字时间；
  - 阅读偏移使用 **当前行 start → 下一行 start** 的实际行时间；
  - 前 15% 行时间保留句首可读（offset=0），随后线性滑到 `总宽-可用宽`，句尾不留下过大空白；
  - 下一句开始/seek 后归零或按新行进度即时定位；
  - 暂停/隐藏由同一局部 Timeline 停止，无追补动画。
- `words` 为空的短句仍然整体居中、静止，不做无意义滑动。
- 有真实 QRC words 的长句继续按 word fraction 在 30%–65% 跟随，本策略不会覆盖它。
- 不新增设置、模式、速度或定时器；仍使用原有 30Hz 局部 Timeline。
