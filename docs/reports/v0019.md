## 2. 实时波形移除

### 2.1 已删除的专用链路

- 删除 `Sources/Valora/AudioTap.swift`（`LiveAudioTap`、Core Audio process tap、aggregate device/IOProc、FFT/vDSP、`AudioTapVerification`）。
- 删除 `--verify-audio-tap` 启动模式和 `AppRuntimeDefaults` 分支。
- 删除 `AppDelegate` 的音频权限请求、启动时 live tap、退出 stop 和 `AppPermissions` 音频注入。
- 删除 `AppPermissions.audioCapture`、`audioEnablePending`、audio pending/generation/attempt 类型与方法、`openAudioPrivacySettings`。
- 删除 `SettingsView` 的“使用实时波形”行、音频 binding/onChange 和音频授权处理。
- 删除 `MusicPreferences.useLiveWaveform`。
- 删除 `CompactPlaybackControl` 的 live 参数、30Hz live 分支和 `LiveAudioTap` 采样；`WaveformClock` 只保留普通非实时波形 tick。
- 删除 `Package.swift` 的 `Accelerate` link；删除 `scripts/package.py` 的 `NSAudioCaptureUsageDescription`。
- 旧 `useLiveWaveform=true` 键仍可能留在旧 `referenceSettingsUI` 字典中，但已没有声明、消费者或启动路径，升级后不会捕获系统声音/请求权限。

### 2.2 保留

- 普通紧凑/展开波形、播放/暂停律动、封面取色；暂停/隐藏/被动屏不会新增 live 刷新。
- 基础 Core Audio 输出/音量控制（`AudioOutputController` / 必要 CoreAudio framework）未删除。
- 歌词、封面、播放控制、音量、标题双击、活动多屏链路未因本批删除音频代码而改动。

## 3. 音乐来源范围核查（未实现差距）

用户的目标是只支持 QQ/网易云/Apple Music/Spotify 等音乐应用，网页/视频不抢占音乐。当前实现仍只读 macOS Now Playing：

- `SystemMediaSource` 读取系统当前媒体流；
- `MediaController.refresh` 没有音乐 bundle allowlist/优先级；
- 当前设置页没有来源选择；
- `mediaBundleIdentifier` 只用于来源激活和命令结算校验。

因此若系统当前媒体是浏览器/视频，本候选仍可能显示它；**独立音乐来源优先没有实现**。本批没有新增多播放器轮询、平台登录、多歌词源或来源过滤，也没有用文案或隐藏浏览器冒充满足。详见 `docs/verification/v0019/music-source-scope.md`。

命令一致性本身仍有保护：发送控制前会校验当前 bundle/track，避免向已切换来源发送旧命令；这不等于音乐来源筛选。
