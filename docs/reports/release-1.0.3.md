# Valora 1.0.3

监控展开面板新增 AirPods 电量信息，版本 1.0.3 / build26，Apple Silicon，macOS 27+。

- 与监控摘要同卡，三列对齐：型号｜耳机电量｜盒电量，无新增菜单栏图标。
- 左右同值显示「全部 99%」，不同显示「左 99% 右 85%」；未知使用 --%，0% 保留。Max 显示整机电量，盒列为未知。
- 接入系统 batteryPercentCase 真实盒电量，沿用既有设备快照，无额外轮询或扫描。
- 具体型号优先从蓝牙 PnP 产品 ID 识别，不依赖耳机是否佩戴或当前音频输出；瞬时型号字段缺失时复用同一设备已确认的型号，不缓存电量。
- 受「设备连接」总开关控制，关闭或断开后隐藏；仅支持已识别 AirPods。刘海、连接动画、歌词和现有圆环不变。

验证：最终独立定向回归 41 项通过；Release 构建、固定证书 strict/deep 签名通过，DMG 完整性校验通过。运行实例已切换到 build26，安装二进制与候选 hash 一致。单次真实诊断确认当前耳机 PnP 产品 ID 为 0x2013，系统有盒电量数据；连续佩戴/摘下等长期组合不宣称全覆盖。本批未重跑产品全量测试。

签名延续 1.0.2 的 Valora Self-Signed 身份，未 Apple 公证。系统未上报盒读数时仍显示 --%，不保证闭盒时持续实时更新。
